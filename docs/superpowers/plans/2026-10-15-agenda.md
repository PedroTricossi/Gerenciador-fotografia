# Agenda Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show every upcoming wedding and scheduled pre-wedding, taken from the contracts, as a chronological list (next 30 or 90 days) and a month calendar, on a new Agenda page that becomes the app's start page.

**Architecture:** A read-only `GET /api/v1/agenda?from=&to=` endpoint, served by a new `AgendaService`, returns ready-made entries (weddings of non-deleted contracts plus their scheduled pre-weddings) sorted by date and time. The frontend adds an Agenda page with a list view and a calendar view that both read that endpoint; its query key sits under the contracts key, so every existing contract, pre-wedding and client mutation already refreshes it.

**Tech Stack:** FastAPI, SQLAlchemy 2, Pydantic 2, pytest; React 19, TanStack Query v5, React Router, openapi-fetch, Vitest + Testing Library + MSW, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-15-agenda-design.md`

## Global Constraints

- Branch `feat/agenda`, based on `main`. No migration, no table or column change.
- The agenda is read-only: no ETag, no audit entry, no pagination.
- Entries: a wedding per non-deleted contract whose `event_date` is in range (time = `coverage_start`, place = contract `venue_name`); a pre-wedding per `prewedding_events` row in range on a non-deleted contract (time and place from the row). A schedule whose service was un-marked still appears.
- Order: date; then time with untimed first; then wedding before pre-wedding; then `contract_id`.
- Only names leave the server (`groom.full_name`, `bride.full_name`, `null` when anonymised). Never CPF or address.
- Range: `from` and `to` required, inclusive; `to` before `from` → 422 on field `query.to` "a data final não pode ser anterior à inicial"; more than 120 days inclusive → 422 on `query.to` "o intervalo máximo é de 120 dias".
- UI copy (verbatim): nav "Agenda" first (Agenda, Contratos, Clientes, Serviços); switches **Lista** | **Calendário** and **Próximos 30 dias** | **Próximos 90 dias**; day headings "Hoje", "Amanhã", otherwise like "sáb., 24/10/2026"; kind labels "Casamento" / "Pré-wedding" (calendar chip suffix "Pré"); empty list "Nenhum ensaio ou casamento nos próximos 30 dias." (or 90); calendar title like "outubro de 2026", buttons "Mês anterior" (‹), "Próximo mês" (›), "Hoje"; weekday headers "Dom Seg Ter Qua Qui Sex Sáb"; overflow "+N mais"; loading "Carregando…"; error "Não foi possível carregar a agenda." with "Tentar de novo"; not-found link "Ir para a agenda".
- `/` redirects to `/agenda`. "Today" is the browser's local date.
- The last view and range are remembered per device in `localStorage` (keys `gerenciador.agenda.view`, `gerenciador.agenda.range`), every access wrapped in try/catch; without them the list and 30 days are shown.
- Calendar: whole weeks starting Sunday; neighbouring-month days faded; today outlined; at most 3 chips per day, then "+N mais" (N = entries − 3). Clicking a day or "+N mais" lists that day's entries below the grid. Below 40rem (640px) wide, days show a dot instead of chips.
- `openapi.json` is gitignored: regenerate with `make api-types`, commit only `frontend/src/api/schema.d.ts`.
- `make check` and `make e2e` must pass at the end. `assert` is banned in `backend/src` (ruff S101).

2. **Late evening:** at 23:30 local time "today" is still today's local date, not tomorrow's UTC date. Test: Task 2 "late in the evening, today is still the local date".

```python
"""The agenda: every wedding and scheduled pre-wedding in a date range."""

import datetime as dt
from dataclasses import dataclass
from typing import Literal

from sqlalchemy import select
from sqlalchemy.orm import Session, lazyload

from gerenciador.db.models import Contract, PreweddingEvent
from gerenciador.domain.contract import ContractRuleError

MAX_DAYS = 120
TO_BEFORE_FROM = "a data final não pode ser anterior à inicial"
TOO_LONG = "o intervalo máximo é de 120 dias"

Kind = Literal["wedding", "prewedding"]

# Only the couple is needed: skip loading the items and the pre-wedding.
_LEAN = (lazyload(Contract.items), lazyload(Contract.prewedding))


@dataclass(frozen=True)
class AgendaEntry:
    contract_id: str
    kind: Kind
    date: dt.date
    start_time: dt.time | None
    venue_name: str
    groom_name: str | None
    bride_name: str | None


def _entry(
    contract: Contract,
    kind: Kind,
    date: dt.date,
    start_time: dt.time | None,
    venue_name: str,
) -> AgendaEntry:
    return AgendaEntry(
        contract_id=contract.id,
        kind=kind,
        date=date,
        start_time=start_time,
        venue_name=venue_name,
        groom_name=contract.groom.full_name,
        bride_name=contract.bride.full_name,
    )


def _order(entry: AgendaEntry) -> tuple[dt.date, bool, dt.time, bool, str]:
    # Untimed first, then by time; at the same time a wedding before a pre-wedding.
    return (
        entry.date,
        entry.start_time is not None,
        entry.start_time or dt.time.min,
        entry.kind != "wedding",
        entry.contract_id,
    )


class AgendaService:
    def __init__(self, session: Session) -> None:
        self._session = session

    def between(self, start: dt.date, end: dt.date) -> list[AgendaEntry]:
        """Shoots from `start` to `end`, both included, on contracts that are not deleted."""
        if end < start:
            raise ContractRuleError("query.to", TO_BEFORE_FROM)
        if (end - start).days >= MAX_DAYS:
            raise ContractRuleError("query.to", TOO_LONG)
        return sorted(
            self._weddings(start, end) + self._preweddings(start, end), key=_order
        )

    def _weddings(self, start: dt.date, end: dt.date) -> list[AgendaEntry]:
        stmt = (
            select(Contract)
            .options(*_LEAN)
            .where(
                Contract.deleted_at.is_(None), Contract.event_date.between(start, end)
            )
        )
        return [
            _entry(
                contract,
                "wedding",
                contract.event_date,
                contract.coverage_start,
                contract.venue_name,
            )
            for contract in self._session.scalars(stmt)
        ]

    def _preweddings(self, start: dt.date, end: dt.date) -> list[AgendaEntry]:
        stmt = (
            select(PreweddingEvent, Contract)
            .join(Contract, Contract.id == PreweddingEvent.contract_id)
            .options(*_LEAN)
            .where(
                Contract.deleted_at.is_(None),
                PreweddingEvent.event_date.between(start, end),
            )
        )
        return [
            _entry(
                contract, "prewedding", row.event_date, row.start_time, row.venue_name
            )
            for row, contract in self._session.execute(stmt).tuples()
        ]
```

```python
from fastapi import APIRouter, Query

from gerenciador.api.deps import Agenda

    service: Agenda,
    start: Annotated[dt.date, Query(alias="from")],
```

```ts
import { formatIsoDate } from "../../domain/dates";

const WEEKDAYS = ["dom.", "seg.", "ter.", "qua.", "qui.", "sex.", "sáb."];

// Dates are "YYYY-MM-DD" strings, computed in UTC so daylight saving never moves a day.
export function toUtc(iso: string): Date {
  const [year = 1970, month = 1, day = 1] = iso.split("-").map(Number);
  return new Date(Date.UTC(year, month - 1, day));
}

export function fromUtc(date: Date): string {
  return date.toISOString().slice(0, 10);
}

export function addDays(iso: string, days: number): string {
  const date = toUtc(iso);
  date.setUTCDate(date.getUTCDate() + days);
  return fromUtc(date);
}

/** 0 for Sunday … 6 for Saturday. */
export function weekday(iso: string): number {
  return toUtc(iso).getUTCDay();
}

export function dayHeading(iso: string, today: string): string {
  if (iso === today) return "Hoje";
  if (iso === addDays(today, 1)) return "Amanhã";
  return `${WEEKDAYS[weekday(iso)] ?? ""}, ${formatIsoDate(iso)}`;
}
```

```ts
import type { AgendaEntryOut } from "../../api/client";
import { coupleLabel } from "../contracts/names";

export function kindLabel(kind: AgendaEntryOut["kind"]): string {
  return kind === "wedding" ? "Casamento" : "Pré-wedding";
}

/** "16:00:00" → "16:00"; no time → "—". */
export function timeLabel(time: string | null): string {
  return time ? time.slice(0, 5) : "—";
}

/** What a screen reader announces for an entry's link. */
export function entryLabel(entry: AgendaEntryOut): string {
  const time = entry.start_time ? `às ${timeLabel(entry.start_time)}` : "sem horário";
  return `${coupleLabel(entry.groom, entry.bride)}, ${kindLabel(entry.kind)}, ${time}, ${entry.venue_name}`;
}

export function entryKey(entry: AgendaEntryOut): string {
  return `${entry.contract_id}:${entry.kind}`;
}

/** Entries grouped by date, keeping the server's order within and between days. */
export function groupByDate(entries: readonly AgendaEntryOut[]): [string, AgendaEntryOut[]][] {
  const groups = new Map<string, AgendaEntryOut[]>();
  for (const entry of entries) {
    const group = groups.get(entry.date);
    if (group) group.push(entry);
    else groups.set(entry.date, [entry]);
  }
  return [...groups];
}
```

```ts
import { useState } from "react";

// A choice remembered on this device. Storage may be missing or blocked; the
// fallback then applies and nothing is remembered.
export function readChoice<T extends string>(key: string, allowed: readonly T[], fallback: T): T {
  try {
    const stored = window.localStorage.getItem(key);
    return allowed.find((option) => option === stored) ?? fallback;
  } catch {
    return fallback;
  }
}

export function writeChoice(key: string, value: string): void {
  try {
    window.localStorage.setItem(key, value);
  } catch {
    // Not remembered; the choice still applies until the page is left.
  }
}

export function useChoice<T extends string>(
  key: string,
  allowed: readonly T[],
  fallback: T,
): [T, (value: T) => void] {
  const [value, setValue] = useState(() => readChoice(key, allowed, fallback));
  const choose = (next: T) => {
    setValue(next);
    writeChoice(key, next);
  };
  return [value, choose];
}
```

```tsx
import styles from "./Agenda.module.css";

type Props<T extends string> = {
  label: string;
  options: readonly { value: T; label: string }[];
  value: T;
  onChange: (value: T) => void;
};

/** A row of buttons of which exactly one is pressed. */
export function Choice<T extends string>({ label, options, value, onChange }: Props<T>) {
  return (
    <div role="group" aria-label={label} className={styles.choice}>
      {options.map((option) => (
        <Button
          key={option.value}
          variant={option.value === value ? "primary" : "secondary"}
          aria-pressed={option.value === value}
          onClick={() => onChange(option.value)}
        >
          {option.label}
        </Button>
      ))}
    </div>
  );
}
```

```tsx
import type { UseQueryResult } from "@tanstack/react-query";
import { Banner, Button } from "../../ui";

/** "Carregando…" while loading, the error banner with a retry on failure, else nothing. */
export function LoadState({ query }: { query: UseQueryResult<unknown> }) {
  if (query.isPending) return <p>Carregando…</p>;
  if (query.isError) {
    return (
      <Banner tone="error">
        Não foi possível carregar a agenda.{" "}
        <Button onClick={() => void query.refetch()}>Tentar de novo</Button>
      </Banner>
    );
  }
  return null;
}
```

```tsx
const RANGES = [

  { value: "90", label: "Próximos 90 dias" },

  const agenda = useAgenda(today, addDays(today, Number(range)));

            <h2 className={styles.dayTitle}>{dayHeading(date, today)}</h2>

  );
```

```ts
const MONTHS = [
  "janeiro",
  "fevereiro",
  "março",
  "abril",
  "maio",
  "junho",
  "julho",
  "agosto",
  "setembro",
  "outubro",
  "novembro",
  "dezembro",
];

/** A calendar month; `month` counts from 0 (January). */
export type Month = { year: number; month: number };

export function monthOf(iso: string): Month {
  const date = toUtc(iso);
  return { year: date.getUTCFullYear(), month: date.getUTCMonth() };
}

export function shiftMonth(current: Month, delta: number): Month {
  const total = current.year * 12 + current.month + delta;
  return { year: Math.floor(total / 12), month: ((total % 12) + 12) % 12 };
}

export function monthTitle(current: Month): string {
  return `${MONTHS[current.month] ?? ""} de ${current.year}`;
}

/** Every day of the whole weeks, Sunday first, that cover the month. */
export function monthGrid(current: Month): string[] {
  const first = fromUtc(new Date(Date.UTC(current.year, current.month, 1)));
  const last = fromUtc(new Date(Date.UTC(current.year, current.month + 1, 0)));
  const end = addDays(last, 6 - weekday(last));
  const days: string[] = [];
  for (let day = addDays(first, -weekday(first)); day <= end; day = addDays(day, 1)) {
    days.push(day);
  }
  return days;
}

/** "5 de outubro de 2026": the accessible name of a day in the grid. */
export function dayLabel(iso: string): string {
  const { year, month } = monthOf(iso);
  return `${Number(iso.slice(8, 10))} de ${MONTHS[month] ?? ""} de ${year}`;
}
```

```tsx
import { useState } from "react";
import { Link } from "react-router";
import { useAgenda } from "../../api/agenda";
import type { AgendaEntryOut } from "../../api/client";
import { Button } from "../../ui";
import { coupleLabel } from "../contracts/names";
import styles from "./AgendaCalendar.module.css";
import {
  type Month,
  dayHeading,
  dayLabel,
  monthGrid,
  monthOf,
  monthTitle,
  shiftMonth,
} from "./agendaDates";
import { EntryList } from "./EntryList";
import { entryKey, entryLabel, groupByDate, timeLabel } from "./entries";
import { LoadState } from "./LoadState";

const WEEKDAYS = ["Dom", "Seg", "Ter", "Qua", "Qui", "Sex", "Sáb"];
const VISIBLE_CHIPS = 3;

function weeksOf(days: string[]): string[][] {
  const weeks: string[][] = [];
  for (let start = 0; start < days.length; start += 7) weeks.push(days.slice(start, start + 7));
  return weeks;
}

type DayProps = {
  day: string;
  month: Month;
  today: string;
  entries: AgendaEntryOut[];
  onOpen: (day: string) => void;
};

function Day({ day, month, today, entries, onOpen }: DayProps) {
  const shown = entries.slice(0, VISIBLE_CHIPS);
  const hidden = entries.length - shown.length;
  const className = [
    styles.day,
    monthOf(day).month !== month.month ? styles.outside : "",
    day === today ? styles.today : "",
  ]
    .filter(Boolean)
    .join(" ");

  return (
    <td className={className} aria-current={day === today ? "date" : undefined}>
      <button
        type="button"
        className={styles.number}
        aria-label={dayLabel(day)}
        onClick={() => onOpen(day)}
      >
        {Number(day.slice(8, 10))}
        {entries.length > 0 && <span className={styles.dot} aria-hidden="true" />}
      </button>
      {shown.length > 0 && (
        <ul className={styles.chips}>
          {shown.map((entry) => (
            <li key={entryKey(entry)}>
              <Link
                to={`/contratos/${entry.contract_id}`}
                className={styles.chip}
                aria-label={entryLabel(entry)}
              >
                {entry.start_time && `${timeLabel(entry.start_time)} `}
                {coupleLabel(entry.groom, entry.bride)}
                {entry.kind === "prewedding" && " · Pré"}
              </Link>
            </li>
          ))}
        </ul>
      )}
      {hidden > 0 && (
        <button type="button" className={styles.more} onClick={() => onOpen(day)}>
          +{hidden} mais
        </button>
      )}
    </td>
  );
}

export function AgendaCalendar({ today }: { today: string }) {
  const [month, setMonth] = useState(() => monthOf(today));
  const [opened, setOpened] = useState<string | null>(null);
  const days = monthGrid(month);
  const agenda = useAgenda(days[0]!, days[days.length - 1]!);
  const byDate = new Map(groupByDate(agenda.data ?? []));
  const openedEntries = opened ? (byDate.get(opened) ?? []) : [];
  const title = monthTitle(month);

  const show = (next: Month) => {
    setMonth(next);
    setOpened(null);
  };

  return (
    <>
      <div className={styles.header}>
        <Button aria-label="Mês anterior" onClick={() => show(shiftMonth(month, -1))}>
          ‹
        </Button>
        <h2 className={styles.title}>{title}</h2>
        <Button aria-label="Próximo mês" onClick={() => show(shiftMonth(month, 1))}>
          ›
        </Button>
        <Button onClick={() => show(monthOf(today))}>Hoje</Button>
      </div>
      <LoadState query={agenda} />
      <table className={styles.grid} aria-label={title}>
        <thead>
          <tr>
            {WEEKDAYS.map((name) => (
              <th key={name} scope="col">
                {name}
              </th>
            ))}
          </tr>
        </thead>
        <tbody>
          {weeksOf(days).map((week) => (
            <tr key={week[0]}>
              {week.map((day) => (
                <Day
                  key={day}
                  day={day}
                  month={month}
                  today={today}
                  entries={byDate.get(day) ?? []}
                  onOpen={setOpened}
                />
              ))}
            </tr>
          ))}
        </tbody>
      </table>
      {opened && openedEntries.length > 0 && (
        <section aria-label={dayHeading(opened, today)} className={styles.selected}>
          <h3 className={styles.selectedTitle}>{dayHeading(opened, today)}</h3>
          <EntryList entries={openedEntries} />
        </section>
      )}
    </>
  );
}
```
